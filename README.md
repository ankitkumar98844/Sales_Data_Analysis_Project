# 📊 Sales Data Analysis Dashboard

## 📖 Project Overview

This Power BI project analyzes sales performance using transactional sales data. The dashboard provides insights into revenue, profit, customer behavior, product performance, and payment preferences through interactive visualizations.

The objective of this project is to transform raw sales data into meaningful business insights that support data-driven decision-making.

---

## 🛠️ Tools & Technologies Used

- Power BI
- Microsoft Excel / CSV Files
- Data Cleaning
- Data Modeling
- DAX Measures
- Data Visualization

---

## 📂 Dataset Used

The project is based on the following datasets:

- **Orders.csv**
- **Details.csv**

These datasets contain information related to orders, sales amount, profit, quantity, categories, sub-categories, customers, states, and payment modes.

## 🔍 Key Business Insights

- Maharashtra generated the highest sales among all states.
- Printers contributed the highest profit among product sub-categories.
- Electronics category sold the highest quantity of products.
- The business recorded its highest profit during October and November.
- COD and UPI were the most preferred payment methods by customers.
- Customer-level analysis helped identify top-performing customers based on sales volume.
